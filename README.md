# The Little Prince — Pixel Book Trailer

A short, fully animated pixel-art trailer. No interaction, just open the page and watch (about 70 seconds, then it loops).

Scenes: starry night with a comet and constellations, the desert with the pilot, the well and the snake, the tiny planet at sunset with the rose, the lamplighter's planet, the fox in the wheat field, the title card, and a black end card with the credit.

The soft lullaby lines that drift behind the scenes are original; edit the `LY` list in the script to change them.

## Run it
Open `index.html` in any modern browser.

## Put it on GitHub Pages
1. Create a new repository and upload `index.html` (and this README).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute your trailer is live at `https://<your-username>.github.io/<repo-name>/`.

## Tweak it
- Credit text: edit `By: ANAM BILAL` in `index.html`.
- Captions and timing: the `CAPS` list in the script.
- Fonts: Cinzel and Cormorant Garamond load from Google Fonts, with Georgia/Times as a fallback.
